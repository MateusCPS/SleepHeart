**Sleep Heart** é um RPG de ação 2D em mundo aberto, desenvolvido na Unity. Escolha entre Guerreiro, Bárbaro, Mago, Paladino ou Druida, explore um mundo construído sobre um espírito colossal e tome decisões que transformam regiões, personagens, alianças e o destino do próprio mundo.

> O projeto encontra-se em fase de protótipo. Os sistemas, cenários, artes e mecânicas apresentados poderão sofrer alterações durante o desenvolvimento.

## Sobre o jogo

O mundo de **Sleep Heart** foi construído sobre o corpo adormecido de um espírito colossal. Durante incontáveis gerações, cidades e reinos cresceram sem conhecer a verdadeira natureza do território onde vivem. Entretanto, mudanças começam a surgir: regiões adoecem, criaturas tornam-se agressivas e antigos fenômenos espirituais voltam a acontecer.

O jogador partirá da cidade central para investigar esses acontecimentos, explorar diferentes regiões e decidir como lidar com as forças que desejam despertar, controlar ou destruir o espírito. As escolhas realizadas ao longo da jornada poderão modificar localidades, relações com personagens, alianças e o desfecho da história.

## Classes planejadas

O jogador poderá escolher uma entre cinco classes, cada uma com identidade, estilo de combate e possibilidades de progressão próprias:

| Classe | Estilo de jogo |
| --- | --- |
| **Guerreiro** | Combate equilibrado, domínio de armas e alta capacidade defensiva. |
| **Bárbaro** | Ataques agressivos, resistência física e poder baseado em fúria. |
| **Mago** | Magias de longo alcance, controle de área e variedade elemental. |
| **Paladino** | Combate corpo a corpo combinado com proteção, cura e poderes sagrados. |
| **Druida** | Magia da natureza, transformações e interação especial com o mundo espiritual. |

## Como executar o projeto

### Requisitos

- Unity Hub;
- Uma versão compatível da Unity 2022.3 LTS;
- Git, caso queira clonar o repositório pelo terminal.

### Instalação

1. Clone este repositório:

   ```bash
   git clone https://github.com/MateusCPS/Sleep-Heart-2026-08-05_11-22-09
   ```

2. Abra o Unity Hub.
3. Clique em **Add** ou **Open**.
4. Selecione a pasta do projeto clonado.
5. Aguarde a Unity importar os assets e instalar as dependências.
6. Abra a cena principal disponível na pasta `Assets`.
7. Pressione o botão **Play** para executar o protótipo.

Caso a Unity solicite a ativação dos backends do novo Input System, confirme a alteração e permita que o Editor seja reiniciado.
